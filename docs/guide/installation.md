# Installation

## Prerequisites

- Python >= 3.12

## Using pip

```sh
pip install git+https://github.com/esther-poniatowski/morpha.git
```

## From Source

1. Clone the repository:

   ```sh
   git clone https://github.com/esther-poniatowski/morpha.git
   ```

2. Install in editable mode:

   ```sh
   cd morpha
   pip install -e .
   ```

For development tools:

```sh
pip install -e ".[dev]"
```
